При разработке веб-синтезатора «ИЗОСИНТ» я использовала ChatGPT Plus и Codex для работы с кодом, настройки звуковых модулей и реализации интерактивных элементов.

1. ChatGPT Plus использовался для разработки и редактирования JavaScript-кода, работы с библиотекой Tone.js, настройки звуковых инструментов и логики управления синтезатором. С его помощью были разработаны музыкальные мелодии для модулей атмосферного давления и воздушного потока, настроены звуковые эффекты, громкость инструментов и взаимодействие кнопок управления.
2. Codex использовался для работы с файлами проекта, корректировки кода HTML и CSS и подключения интерактивных элементов. Основной задачей было сохранить разработанный визуальный стиль и обеспечить корректную работу всех элементов синтезатора.
